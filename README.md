# psx-data

Public Pakistan Stock Exchange snapshot, refreshed every ~5 minutes during
market hours (Mon–Fri 09:30–15:30 PKT) by the
[psx-data-fetch](https://github.com/) scraper running locally.

**Live URL (served by GitHub Pages, crawler-friendly):**
https://bigbajwatv-alt.github.io/psx-data/latest_snapshot.json

This URL is overwritten in place each cycle, so the URL itself is stable.

For schema details, see the upstream tool's README.
